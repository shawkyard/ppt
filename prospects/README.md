# Utah Website Prospects — August 2026

Prospect list for the web design business: Utah small businesses whose current
website runs on Wix or GoDaddy Website Builder (or barely exists at all), with
the owner / decision-maker named for each.

## File

- `utah-website-prospects-2026-08.csv` — 61 rows, Apollo-import-ready.

## How it was built

1. Apollo people search: owners/founders/C-suite at Utah companies (1–50
   employees) whose website technology is tracked as **Wix** or **GoDaddy
   Website Builder** (1,573 total matches in Apollo; 258 GoDaddy-only).
2. Top local-service prospects were then verified one-by-one via public web
   sources (LinkedIn, company sites, BBB, Yelp, local news) to confirm the
   owner's full name, city, and domain.

## Tiers

- **A+ / A (verified)** — full owner name confirmed via public sources.
  Ready to upload and sequence.
- **B+ / B (partial)** — company + first name + title confirmed in Apollo;
  last name was masked by Apollo's search API (shown as a hint in Notes).
  Upload anyway — Apollo will match and reveal the full name + email on
  enrichment.

## Uploading to Apollo

Import as **Contacts** (Settings → Import → CSV). Map:
`First Name`, `Last Name`, `Title`, `Company`, `Website` → Company Website,
`City`, `State`. `Industry`, `Platform Signal`, `Tier`, and `Notes / Pitch
Angle` can be mapped to custom fields for sequencing/personalization.
Then run enrichment to fill emails/phones (and reveal Tier B last names).
