How the expected case gets to net contribution

Incremental revenue is decomposed correctly — the AOV-only effect plus the frequency-only effect plus their interaction — then adjusted for incrementality and gross margin, then all program costs are subtracted. (Common spreadsheets count only the interaction term and understate the benefit.)

11  What could cause underperformance

The model assumes competent execution.

  • Weak member recruitment — the #1 failure mode; a program with no members returns nothing.
  • Under-promotion — thin email/SMS/POS/packaging activation.
  • Poor reward perceived value or margin-destroying discounts.
  • Implementation quality — not following vendor best practices.
  • External — economic conditions, aggressive competitor offers.
The honest caveatThese projections assume the brand follows reasonable implementation and operating best practices from the selected vendor. A company that barely promotes its program should not expect modeled results. That is a feature of the analysis, not a hedge.
