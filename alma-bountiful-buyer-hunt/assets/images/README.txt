Brand & agent image drop-in slots
=================================

The report auto-displays your REAL images the moment you add these files here
(exact names, no code changes needed):

  alma-logo.png       ->  Full Alma AI Revenue Hunter brand lockup (the chrome
                          shark + wordmark + "HUNT · GATHER · CLOSE · GROW" +
                          PrestigeSalesExperts.com). Shown as the masthead hero
                          on index.html. Recommended: transparent PNG, ~1400px
                          wide. Until present, a built-in SVG shark emblem +
                          styled wordmark is shown as a faithful placeholder
                          (same black / chrome / molten-orange colors).

  agent-headshot.jpg  ->  Square photo of Chad Buttars, shown in the agent card.
                          Until present, a "CB TEAM" monogram is shown.

alma-emblem.svg       ->  The built-in fallback shark emblem (ships with the
                          report; you can leave it as-is or replace it).

Only use images you are authorized to use (your own brand/team/brokerage
assets). Do not use third-party listing photos where licensing prohibits
redistribution.
