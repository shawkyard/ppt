The hard question

Member revenue is not the same as loyalty ROI.

A program can generate a great deal of revenue from members and still fail to create incremental profit. The revenue was often going to happen anyway. Alma separates the change loyalty actually caused—more active members, more frequent visits, larger baskets, better retention—from revenue you already had, then weighs it against the full cost of creating it.

Weaker measurement

  • ✕ Counts all member revenue as loyalty revenue
  • ✕ Uses enrollment as a stand-in for participation
  • ✕ Ignores margin and program costs
  • ✕ Treats correlation as guaranteed causation
  • ✕ Reports one precise-looking number

The Alma way

  • ✓ Isolates incremental behavior change
  • ✓ Separates active members from names enrolled
  • ✓ Evaluates value after full program cost
  • ✓ Compares members with baselines & controls
  • ✓ Shows a range with an honest confidence level

Everything you need to know

Questions finance and marketing both ask.

Can Alma tell whether a company will make money with loyalty? +
Alma estimates the conditions under which a well-designed program is likely to produce positive incremental contribution—the required active membership, behavior lift, margin, cost, and payback thresholds. It cannot guarantee future behavior or execution. The purpose is to replace a vague promise with a transparent range and a clear list of what must be true.
How accurate is the estimate? +
The result is only as strong as the evidence behind it, so Alma shows assumptions, scenarios, and a confidence level rather than pretending every program can be measured with identical precision. A company with detailed customer, transaction, margin, and cost data receives a stronger measurement than one using only public benchmarks. In both cases, the model shows what is known, what is estimated, and what data would improve the answer.
Does Alma count all member revenue as loyalty revenue? +
No. Alma focuses on measurable change that can reasonably be attributed to loyalty—incremental purchase frequency, order value, retention, and cross-sell—then evaluates that value after the relevant program costs. It does not automatically treat existing revenue from members as incremental.
What if I don't have all the data? +
Every input accepts an estimate. Where an input is assumed, the result identifies the assumption and its confidence level so it can be replaced as better data becomes available. You get a useful directional answer immediately, and a stronger one as you add real figures.
Does Alma replace my loyalty platform? +
No. Loyalty platforms run programs, rewards, and member experiences. Alma is the ROI intelligence and decision layer that helps vendors and brands estimate opportunity, build the financial case, prioritize action, and measure results against the original business case.
